
# 🎮 Adivinha de Números

Um mini jogo desenvolvido em **Java Swing**, no qual o objetivo é adivinhar o número escolhido pelo "gênio" entre 1 a 5.

## 🚀 Tecnologias utilizadas

- **Java:** linguagem utilizada no desenvolvimento.
- **NetBeans:** ambiente de desenvolvimento do projeto.
- **Java Swing:** recurso para criação de interface gráfica em Java.

## ▶️ Como executar o programa

**IMPORTANTE:** Para executar o jogo, é necessário ter o **Java instalado** no computador.

1. Baixe ou clone este repositório.
2. Verifique se o Java está instalado.
3. Acesse a pasta `dist` do projeto.
4. Execute o arquivo `.jar` disponível nessa pasta.
